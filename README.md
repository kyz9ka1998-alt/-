# ⚽ Футбольный английский

Веб-приложение для Романа (6 лет): английский язык в футбольном формате.
Открывается в Safari на iPhone/iPad, можно добавить на экран «Домой» как обычное приложение.

## Как устроено
- **Уроки:** каждая тема (юнит) = 2 тренировки по 3 новых слова + «Матч за кубок» (повторение).
- **Упражнения:**
  1. *Новое слово* — картинка, озвучка (обычно и медленно 🐢), перевод.
  2. *Пенальти* — слышишь слово и бьёшь в ворота по нужной картинке; ошибёшься — вратарь поймает.
  3. *Скажи сам* — распознавание произношения через микрофон (как в Duolingo), мягкая оценка детской речи.
- **Награды:** за тренировку — новый навык футболиста (набивает 10/20/50/100 раз, коленом, головой,
  финты «Рулетка», «Радуга», «Ножницы», удар в девятку, удар через себя). За матч — кубок и повышение в карьере:
  дворовая команда → ДЮСШ → академия → юноши → молодёжка → основа → капитан.
- **Для родителей:** ⚙️ на главном экране (вопрос-пример), там настройки и сброс прогресса.

## Файлы
- `js/data.js` — программа: темы, слова, навыки, ступени карьеры. **Сюда добавляются слова из учебника.**
- `js/player.js` — анимированный футболист (SVG) и анимации навыков.
- `js/speech.js` — озвучка, распознавание речи, звуки.
- `js/app.js` — экраны и логика уроков.

## Локальный запуск
```
python3 -m http.server 8000
```
и открыть http://localhost:8000. Для микрофона на телефоне нужен HTTPS (GitHub Pages / Netlify дают его автоматически).

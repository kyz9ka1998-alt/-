# ⚽ Футбольный английский

Веб-приложение для Романа (6 лет): английский язык в футбольном формате.
Открывается в Safari на iPhone/iPad, можно добавить на экран «Домой» как обычное приложение.

## Как устроено
- **Программа** — по книге «Английский для малышей» (Шишкова, Вербовская, под ред. Н. А. Бонк): уроки 2–15 и 18–21
  + бонусная тема «Football». Тема = 1–2 тренировки (новые слова) + «Матч за кубок» (фразы и диалоги).
  Урок 1 (сказка про звуки) не перенесён — в нём нет слов для заучивания.
- **Задания:**
  - *Новое слово / фраза* — картинка, транскрипция, чтение русскими буквами, перевод, пример, объяснение.
  - *Пенальти* — услышь слово и забей в нужную картинку.
  - *Прочитай* — выбери написанное слово к картинке.
  - *Найди пару* — картинка ↔ слово, животное ↔ его еда.
  - *Сколько?* — «How many frogs?» → *three frogs*.
  - *Рифма* — «I can see a cat and a …» → *bat*.
  - *Скажи* и *Вспомни сам* — произношение через микрофон (как в Duolingo); «Вспомни» — по-русски → сказать по-английски.
  - *Диалог* — зверёк просит («Give me some cheese»), нужно дать нужное и ответить голосом («Here you are!»).
  - *Собери фразу* — из слов-карточек.
  - *Кто исчез?* — запомни картинки, одна пропадёт: «What's missing?»
  - *Да или нет* — «Is this a bird?» / «Is this a big hat?» → «Yes, it is.» / «No, it isn't. It's a little hat.»
- **Повторение:** кнопка 🔁 на главном экране. Слова из пройденных уроков возвращаются по интервалам
  (1, 2, 4, 7, 14, 30 дней); слово с ошибкой возвращается уже на следующий день.
- **Награды:** за каждую новую тренировку — навык футболиста, за матч — кубок и повышение в карьере.
- **Для родителей:** ⚙️ на главном экране — настройки, код прогресса для переноса на другое устройство, сброс.

## Файлы
- `js/data.js` — программа: темы, слова, навыки, ступени карьеры. **Сюда добавляются слова из учебника.**
- `js/player.js` — футболист на шарнирном скелете (колени, локти, обратная кинематика ног), стадион, вратарь, анимации 16 навыков.
- `js/speech.js` — озвучка, распознавание речи, звуки.
- `js/lesson.js` — все типы заданий.
- `js/app.js` — экраны, награды, прогресс.

## Локальный запуск
```
python3 -m http.server 8000
```
и открыть http://localhost:8000. Для микрофона на телефоне нужен HTTPS (GitHub Pages / Netlify дают его автоматически).
